# Contribuir al proyecto

Gracias por contribuir al MVP de vigilancia tecnológica.

## Reglas básicas

- No subas datos reales, PDF, Excel ni otros documentos del corpus.
- No subas `.env`, claves API, tokens ni credenciales.
- Mantén los archivos generados dentro de `outputs/` fuera del repositorio.
- Crea una rama para cada cambio y usa commits pequeños y descriptivos.
- Ejecuta `pytest` antes de realizar el commit.
- Actualiza documentación y pruebas cuando cambie el comportamiento.

Antes de abrir una contribución, revisa `repo_checklist.md`.
